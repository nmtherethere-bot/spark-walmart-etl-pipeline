# 🚀 Walmart Sales ETL Pipeline (Apache Spark + Docker + Java)

A production-grade **ETL (Extract–Transform–Load) pipeline** built using **Apache Spark (Java)** running inside **Docker**, transforming Walmart sales data and writing output in optimized **Parquet** format. This project is designed to demonstrate real-world data engineering best practices including schema standardization, feature engineering, partitioning, and containerized execution.

---

# 📌 **Project Overview**

This ETL pipeline performs:

* **Extract:** Load raw Walmart sales CSV data
* **Transform:** Clean, rename columns, normalize schema, compute metrics
* **Load:** Write transformed output to Parquet or BigQuery (configurable)

The pipeline supports a **dry-run mode** for local testing and a **production mode** for BigQuery ingestion.

---

# 🧱 **Tech Stack**

* **Apache Spark 3.5.0**
* **Java 11**
* **Docker / Docker Compose**
* **Parquet (Snappy compression)**
* Optional: Google BigQuery for production loads

# 🐳 **Running Spark in Docker**

Start the environment:

```
docker-compose up -d
```

Enter the container:

```
docker exec -it spark-runner bash
```

Verify Spark:

```
/opt/spark/bin/spark-shell
```

---

# 🚀 **Build the ETL JAR**

Run this from the project root:

```
mvn clean package -DskipTests
```

This generates:

```
target/walmart-spark-etl-1.0.0.jar
```

---

# ▶️ **Run ETL in Dry-Run Mode (No BigQuery Needed)**

Ideal for local development.

```
/opt/spark/bin/spark-submit \
  --class com.example.walmart.etl.ETLJob \
  /app/walmart-spark-etl-1.0.0.jar \
  --inputPath=/data/walmart_sales.csv \
  --mode=dryrun \
  --bqProject=dummy-project
```

### ✔ Output

* Shows transformed rows
* Prints schema
* Does NOT write to BigQuery

---

# 📤 **Save Dry-Run Output to Parquet**

```
/opt/spark/bin/spark-submit \
  --class com.example.walmart.etl.ETLJob \
  /app/walmart-spark-etl-1.0.0.jar \
  --inputPath=/data/walmart_sales.csv \
  --mode=dryrun \
  --bqProject=dummy \
  --outPath=/data/output
```

Check output:

```
ls -lh /data/output
```

You should see:

```
part-00000-*.snappy.parquet
_SUCCESS
```

# 🧠 **Transformations Performed**

### ✔ Column Renaming

| Raw Column   | New Column |
| ------------ | ---------- |
| invoice_id   | order_id   |
| date         | order_date |
| product_line | category   |
| branch       | store_id   |

### ✔ Feature Engineering

* `product_name` derived from category
* `gross_sales = unit_price * quantity`
* `order_year`, `order_month` extracted from `order_date`

### ✔ Data Cleaning

* Null handling
* Date parsing
* Schema standardization

# 🌐 **Production Mode (Write to BigQuery)**

Use this only when connecting to Google Cloud:

```
/opt/spark/bin/spark-submit \
  --class com.example.walmart.etl.ETLJob \
  /app/walmart-spark-etl-1.0.0.jar \
  --inputPath=/data/walmart_sales.csv \
  --mode=append \
  --bqProject=<project-id> \
  --bqDataset=<dataset> \
  --bqTable=<tablename> \
  --tempGcsBucket=<gcs-temp-bucket>
```
